Cabor terpilih

Buat pertandingan · Sesi aktif · Histori per cabor

Link Tree langsung mengelola halaman komunitas, tanpa pilihan cabor. Scoreboard tidak dikunci satu cabor profil. Berganti cabor tidak mereset sesi; cabor sesi yang sudah dibuat tidak dapat ditukar. Ini rencana navigasi, bukan menu aplikasi yang sudah terpasang.

1. Perjalanan pengurus komunitas

  1. 01 · AKSES

    Komunitas, Alat, lalu cabor

    Alat > Scoreboard > Basket. Server memeriksa akun aktif dan kewenangan pengurus; satu komunitas boleh memakai banyak cabor.

  2. 02 · MODE

    Main Cepat / Buat Pertandingan

    Main Cepat tanpa histori otomatis. Buat Pertandingan mencatat latihan/latih tanding. Kontrol sama lengkap; tidak wajib roster, event atau alat.

  3. 03 · SESI

    Siapkan scoreboard

    Satu sesi aktif. Buka konsol utama, konsol shot, papan utama dan dua shot clock dari sesi yang sama.

  4. 04 · OPERASIKAN

    Kirim aksi, tunggu ACK

    Skor, foul, timeout, periode, possession dan clocks. Applied baru dianggap berhasil; konflik tidak ditimpa.

  5. 05 · TINJAU

    Hentikan clocks dan selesai

    Periksa skor lalu konfirmasi. Waktu periode habis tidak otomatis menyelesaikan pertandingan.

  6. 06 · PENCATATAN

    Catat Hasil atau tidak

    Main Cepat menawarkan Catat Hasil atau Selesai Tanpa Mencatat. Hasil tercatat privat/nonresmi; sesi selesai read-only.

2. Satu otoritas, bukan timer terpisah pada setiap layar

Koneksi putus: kontrol dinonaktifkan, display menandai stale. Deadline server dapat tetap berjalan. Tidak pindah authority otomatis; klik offline tidak diantrekan.

4. Histori komunitas berbeda dari hasil resmi

Latihan / latih tanding awal

  • Pengurus mencatat pertandingan.
  • Clocks berhenti, tinjau dan konfirmasi selesai.
  • Hasil recorded, nonresmi.
  • Histori privat; nama lawan bukan bukti persetujuan.

Konfirmasi lawan · lanjutan

  • Komunitas lawan menerima linkage.
  • Satu pertandingan bersama, bukan dua hasil terpisah.
  • Baru boleh dilabeli confirmed sesuai penerimaan.
  • Tidak otomatis menjadi hasil resmi turnamen.

Turnamen · lanjutan

  • Gunakan Game existing.
  • Scoreboard menghasilkan ringkasan provisional.
  • Organizer berizin meninjau dan memfinalisasi.
  • Event mengubah hasil, bracket dan klasemen.

6. Prioritas dan batas

Bangun pertama

Engine + fixtures; buat pertandingan; dua konsol; tiga display; simpan/lanjutkan sesi; selesai dan histori privat.

Default latihan basket

4 × 10 menit, overtime 5 menit, shot 24/14. Stop game menghentikan shot; shot habis tidak otomatis menghentikan game. Timeout clock terpisah dari timeout terpakai.

Tunda sampai perlu

Offline virtual/PWA, 3x3, operator khusus, acceptance lawan, publikasi tanpa login, turnamen, pairing dan firmware perangkat.

Status nyata

PRD dan audit tersedia. Lima tes demo Wokwi lokal lulus; belum tes basketball.v1, UI virtual ActStation, UAT atau perangkat nyata. Preset latihan bukan sertifikasi FIBA.
