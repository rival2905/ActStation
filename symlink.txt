PERILAKU KEAMANAN SAAT INI

- Default AGENT_OFFICE_ENABLED=false.
- Default loopback HTTP=false.
- IP diperiksa dari REMOTE_ADDR sebelum query DB; forwarded headers tidak dipercaya.
- Registry privat terenkripsi AES-256-GCM memakai master key terpisah dari APP_KEY.
- HMAC-SHA256 v1 mengikuti bytes dan urutan field Modul 13.
- Timestamp toleransi 60 detik.
- Nonce diklaim setelah signature valid, retensi 300 detik.
- Replay/quota memakai file lock dan atomic replacement, lintas proses pada satu node.
- Bearer Sanctum persisten, principal aktif, expiry, binding key/principal dan ability agent:health-read.
- Wildcard dan session manusia tidak menggantikan bearer bot.
- Quota 60 request/menit per principal lintas token; pre-auth 120/menit per peer.
- Health hanya GET tanpa body/query; ambiguity Content-Length dan header invalid ditolak.
- Audit non-DB memakai field allowlist, tanpa Authorization, secret atau body.
- Health melakukan SELECT 1 nyata dan mengukur latency; n8n_status=not_checked. Tidak mengirim webhook.

Jangan mengganti nonce store dengan default cache tanpa membuktikan atomicity lintas worker dan memastikan bukan DB bisnis/process-local memory. Jangan menghapus state replay untuk memperbaiki error.
